# Instashop

Instashop is a marketplace for Instagram sellers. Right now most small sellers in India sell through DMs: buyers ask for price, send screenshots, and everything gets lost in chats. Instashop gives those sellers a proper place to list their products, and gives buyers one place to browse them, discover new shops, and follow the ones they like on Instagram.

It's built for young Indian shoppers and the small sellers they already buy from. Launching 1 January.

## How it works

1. A seller joins Instashop and lists their products.
2. Buyers browse products and explore shops in one place.
3. Buyers follow the shops they like on Instagram, so sellers keep their audience.

## Features

**For buyers**
- Browse products from lots of Instagram sellers in one place
- Discover new shops instead of hunting through hashtags
- Follow any shop on Instagram straight from its page

**For sellers**
- A clean product listing instead of selling through DMs
- A shop page that sends buyers back to their Instagram
- Seller onboarding through a simple form

**Coming soon**
- AI product import: products get pulled automatically from a seller's Instagram posts, so they don't have to list everything by hand

## About this repo

This repo is the Instashop home page redesign. It's frontend only, with no backend, so everything on the page is static or mocked. The look is bold and pink, with smooth scroll animations and a 3D product spotlight.

React, Vite, Tailwind CSS, shadcn/ui, framer-motion, GSAP + ScrollTrigger, react-three-fiber and drei, Lenis.

## Running locally

You need Node.js and npm ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
git clone https://github.com/Harshun0/pink-motion-studio.git
cd pink-motion-studio
npm i
npm run dev
```
